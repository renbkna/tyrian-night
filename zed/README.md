# Tyrian Night for Zed

Zed theme extension for Tyrian Night, Tyrian Dusk, and Tyrian Dawn.

Install it locally with `zed: install dev extension` and select this `zed` directory.

For closest parity with the VS Code package, treat `settings.example.json` as the authoritative companion settings file and copy it into your Zed `settings.json` where supported. The theme extension owns colors; font family, font features, line height, UI font, bracket colorization, indent guides, terminal contrast, and semantic-token mode are Zed user settings.

For registry publishing from the parent repository, add this extension as a submodule/path entry with `path = "zed"`.
