# Tyrian Night for Zed

Zed theme extension for Tyrian Abyss, Tyrian Night, Tyrian Nocturne, Tyrian Night Old, and Tyrian Dawn.

Install it locally with `zed: install dev extension` and select this `apps/zed` directory.

For closest parity with the VS Code package, treat `settings.example.json` as the authoritative companion settings file and copy it into your Zed `settings.json` where supported. The theme extension owns colors; font family, font features, line height, UI font, bracket colorization, indent guides, inlay hints, panels, edit-prediction posture, language servers, formatters, file type mapping, terminal contrast, and semantic-token mode are Zed user settings.

For registry publishing from the parent repository, add this extension as a submodule/path entry with `path = "apps/zed"`.
